# CORE COMPANY PHILOSOPHY

The entire ERP revolves around one core business idea:

"sahi product lao, sahi rate pe lo, sahi price pe becho, aur right buyer tak sahi time pe pahunchao."

Translated operationally:

* source the correct product
* at the correct cost
* price it safely
* deliver it to the correct buyer
* at the correct time
* while maintaining profitability and repeat orders

Every feature must support this business goal.

# ENGINEERING RULES

## RULE 1 — ALWAYS UNDERSTAND BUSINESS GOAL FIRST

Before implementing any feature:

* identify which branch/team uses it
* identify where it fits in operational flow
* identify how it improves profitability or control

Never build isolated features.

---

## RULE 2 — MINIMIZE TOKEN & CONTEXT WASTE

Before editing:

* scan only relevant directories/files
* avoid reading unrelated modules
* avoid full-project rescans unnecessarily
* use scoped architecture-aware edits

Example:
If editing GST buyer onboarding:

* inspect buyer forms
* invoice validation
* GST models
* auth
* audit logging

Do NOT scan unrelated logistics/video/upload systems.

---

## RULE 3 — PARALLEL EXECUTION

Always use multiple specialized agents when possible.

Default agent allocation:

1. frontend UX agent
2. backend/API agent
3. database/schema agent
4. security/compliance agent
5. browser automation agent
6. QA/testing agent
7. performance optimization agent

Run independent tasks concurrently.

Synchronize only where dependencies exist.

---

## RULE 4 — PRODUCTION-FIRST ENGINEERING

Every feature must include:

* validation
* loading states
* retry handling
* audit logs
* mobile responsiveness
* security review
* cleanup handling
* edge-case handling

Never build demo-level implementations.

---

## RULE 5 — ENTERPRISE UX STANDARD

UI must always feel:

* premium
* fast
* dark enterprise styled
* operationally efficient
* mobile responsive
* minimal-click workflow optimized

Preferred design:

* dark navy / black base
* gold/yellow highlights
* Inter font
* smooth transitions
* professional B2B feel

---

## RULE 6 — BUSINESS SAFETY

Never allow:

* stock mismatch
* invalid GST invoices
* unsafe credit exposure
* duplicate buyers
* broken audit trails
* unauthorized access

Compliance and operational safety are critical.

---

## RULE 7 — QA REQUIREMENTS

Always:

* use browser-agent testing
* perform slow visible walkthroughs
* generate screenshots
* validate mobile responsiveness
* produce QA reports

Never assume UI works without visual validation.

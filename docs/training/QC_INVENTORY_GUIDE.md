# QC / Inventory Team Guide

## 📌 Department Purpose
- **Responsibility:** Receive stock, perform quality checks, manage inventory levels, track batch numbers.
- **Goal:** Maintain high‑quality inventory with accurate stock counts.
- **Business Importance:** Directly affects production efficiency and order fulfillment.

## 🔐 Login Instructions
1. Open the ERP URL and log in with your corporate credentials.
2. After authentication you will see the **QC & Inventory Dashboard**.
3. Role `QC_INVENTORY_TEAM` restricts view to stock intake, QC forms, and inventory reports.

## 📅 Daily Workflow
1. **Stock Intake** – Navigate to **Inventory → Stock Intake**.
2. Select the pending **Purchase Order** and enter received quantities.
3. **Quality Check** – Open the QC form, record defects, and approve/reject batches.
4. **Batch Tagging** – Assign batch numbers and expiry dates.
5. **Inventory Update** – System automatically updates stock levels.
6. **Report Generation** – Export daily QC report for the founder.

## 🛠️ Real‑Life Example
- Receive 200kg of cotton from supplier XYZ.
- Log intake, run QC → 5% defect flagged.
- Reject defective batch, approve 190kg, assign batch #B2026‑01.
- Inventory now shows 190kg available for production.

## 🚫 Mistakes To Avoid
- **Skipping QC** – leads to defective products.
- **Incorrect batch numbers** – causes traceability issues.
- **Not updating expiry** – may result in stock spoilage.

## ✅ SOP Checklist (Daily)
- [ ] Verify pending PO list.
- [ ] Perform stock intake for all received shipments.
- [ ] Complete QC forms for each batch.
- [ ] Reconcile inventory counts.
- [ ] Export QC summary report.

## 📞 Escalation Flow
- **QC failure** → Notify **Technical Team** for root‑cause analysis.
- **Inventory discrepancy** → Alert **Founder** via admin dashboard.
- **Supplier issues** → Contact **Purchase Team**.
